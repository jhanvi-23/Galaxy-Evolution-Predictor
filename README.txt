GALAXY EVOLUTION PROJECT WEBSITE

CONTENTS
- index.html: complete responsive project website
- assets/: four diagnostic figures extracted from the final scientific report
- Galaxy_Evolution_ML_Final_Report.pdf: final project report

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open the galaxy_website folder.
3. Double-click index.html. The page opens in your browser.

PUBLISH ON GITHUB PAGES (same GitHub repository)
1. Open https://github.com/jhanvi-23/Galaxy-Evolution-Predictor
2. Click Add file > Upload files.
3. Upload the CONTENTS of this folder (index.html, assets folder, PDF and README) into the repository ROOT. Do not upload the outer galaxy_website folder as a nested folder.
4. Commit the changes to the main branch.
5. Open repository Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait for GitHub Pages to publish. The website URL will be shown in Settings > Pages.

IMPORTANT
- Do not delete or move the existing 08_Web_App_Deployment folder. Render uses it.
- The prediction buttons link to the existing live Render app: https://galaxy-evolution-predictor.onrender.com
- The website does not contain or expose model pickle files.

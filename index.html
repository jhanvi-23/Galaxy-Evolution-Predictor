01 / THE PROJECT

Turning astronomical observations into predictions.

The project builds two separate regression models from a large photometric galaxy catalogue. The goal is to reproduce the catalogue's estimated stellar-mass and star-formation-rate values from a consistent set of input features.

TARGET 01

Stellar mass

Predicts the catalogue estimate stored in MASS_MED_GaZNet, using nine GAaP magnitude bands, their associated errors, and GaZNet redshift.

TARGET 02

Star formation rate

Predicts the catalogue estimate stored in SFR_MED_GaZNet using the same 19 input features, with separate model fitting and evaluation.

02 / METHODOLOGY

A reproducible modelling workflow.

Two regression approaches were compared. Model selection used validation performance, and the selected model was evaluated on a held-out test set.

STEP 01

Catalogue preparation

KiDS DR4 data were audited and 19 predictors plus two target columns were selected. No missing values were found in the selected modelling columns.

STEP 02

Model comparison

Ridge Regression with standardisation was compared against HistGradientBoostingRegressor, with separate estimators for each target.

STEP 03

Evaluation & diagnostics

MAE, RMSE and R² were measured on the held-out test set. Residuals, subgroup behaviour and feature importance were also examined.

03 / TEST-SET RESULTS

Two targets. Different levels of predictability.

HistGradientBoosting was selected for both targets based on validation results. The following metrics are from the final held-out test set.

Scientific caution: These models predict GaZNet-associated catalogue estimates, not independently verified physical ground truth. GaZNet is also an input feature, so shared catalogue information may contribute to the strong stellar-mass result. Target units and exact logarithmic conventions were not confirmed; metrics are reported in the targets' native numerical scales.

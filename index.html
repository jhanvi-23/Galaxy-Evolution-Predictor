01 / PROJECT OVERVIEW

Reading the
universe through
galaxy data.

Galaxies carry measurable clues about their evolution. This project uses photometric observations and machine learning to estimate two important galaxy properties: stellar mass and star-formation rate.

From astronomical catalogue measurements to data-driven predictions.

AN ABSTRACT VIEW OF A SPIRAL GALAXY

THE PROJECT AT A GLANCE

Two properties. One astronomical dataset.

The workflow learns relationships between catalogue photometry, redshift information, and the catalogue's estimated galaxy properties. Two separate regression models are trained for the two targets.

01 / DATA

KiDS DR4 catalogue

A large photometric galaxy catalogue provides the observations used to prepare the machine-learning dataset.

02 / LEARNING

Regression models

Separate HistGradientBoostingRegressor models learn patterns for stellar mass and star-formation rate.

03 / OUTPUT

Galaxy estimates

The trained models return predicted values for both target properties from the selected input features.

02 / METHODOLOGY

Turning observations into predictions.

The modelling process transforms selected catalogue measurements into structured inputs, trains two regression models, and evaluates their predictions on held-out test data.

01

Catalogue preparation

Start with the KiDS DR4 catalogue and select the relevant observations and target columns.

02

Feature selection

Use nine GAaP magnitude bands, their nine associated errors, and the GaZNet redshift value: 19 inputs in total.

03

Two model training tasks

Train one HistGradientBoostingRegressor for stellar mass and another for star-formation rate.

04

Testing and evaluation

Evaluate both models on held-out test data using MAE, RMSE, and the coefficient of determination (R²).
